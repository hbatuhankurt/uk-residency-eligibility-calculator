# uk-residency-eligibility-calculator

## 🇬🇧 English

A Python tool to calculate UK ILR (Indefinite Leave to Remain) and British citizenship eligibility based on your travel history.

- **Checks 180-day and 450-day rules**
- **Processes travel dates from your data**
- **Generates a detailed Excel report with summaries and conditional formatting**
- **Ideal for tracking UK residency requirements for immigration and naturalization**

### Usage

1. Clone the repository:
    ```
    git clone https://github.com/hbatuhankurt/uk-residency-eligibility-calculator.git
    ```
2. Install dependencies:
    ```
    pip install pandas openpyxl
    ```
3. Edit the travel data in the script as needed.
4. Run the script:
    ```
    python main.py
    ```
5. The Excel report (`UK_Residency_Eligibility_Calculation.xlsx`) will be generated in the project folder.
