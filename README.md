# uk-residency-eligibility-calculator
Python tool to check UK ILR and citizenship eligibility based on your travel history. Calculates limits, checks rules, and generates a summary Excel report. About Birleşik Krallık ILR ve vatandaşlık başvurusu için seyahat geçmişinize göre uygunluk hesaplayan, özet ve Excel raporu oluşturan Python aracı.
